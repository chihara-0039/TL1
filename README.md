# TL1 Blenderレベルエディタ

Blenderでステージを編集し、JSON形式で出力した配置情報を自作ゲームエンジンへ読み込むレベルエディタです。
エンジン実行中にJSONが更新された場合は変更を検出し、確認後に再読み込みできます。

# 加点項目

* ローダーと配置
  * Blenderで配置した複数種類のモデルについて、位置・回転・拡縮をJSONへ出力し、自作エンジン上で再現します。
* コライダーをゲーム側当たり判定に適用
  * Blender上で設定したBOXコライダーをJSONへ出力し、自作エンジンの当たり判定へ使用します。
* ホットリロード（ゲーム側）
  * エンジン実行中に外部レベルファイルの変更を検出し、確認ダイアログからステージを再読み込みします。
* 無効フラグの追加
  * Blender上のオブジェクトごとに出力の有効・無効を設定できます。
* SpawnPointの配置
  * Blender上でプレイヤーの開始地点を設定し、ゲーム開始時のスポーン位置へ反映します。

# 独自実装

* 外部レベル一覧とステージエディタ連携
  * `Resources/Levels`内のJSONを一覧表示し、選択した外部ステージをステージエディタへ読み込みます。
* 外部ステージのゲームプレイ確認
  * 読み込んだ配置とコライダーを、そのままゲームプレイ画面で確認できます。
* 再読み込み確認ダイアログ
  * 意図しない編集中データの反映を防ぐため、ファイル変更時に確認してから再読み込みします。

# 確認手順

1. Blenderで`CG2_01/project/Tools/Blender/level_editor.py`をアドオンとして有効化します。
2. `CG2 Level Editor`からステージを編集し、`CG2_01/project/Resources/Levels/game_level.json`へ出力します。
3. 自作エンジンを起動し、Stage EditorのExternal Levelから`game_level.json`を読み込みます。
4. ゲームプレイ画面でモデルの配置、プレイヤー開始地点、当たり判定を確認します。
5. エンジン実行中にBlenderから再度JSONを出力し、変更検出ダイアログから再読み込みします。
